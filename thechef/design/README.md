# The Chef – Design-Vorlagen (Referenz)

HTML-Mockups als Bauplan, NICHT der App-Code. Farben, Abstände, Radien, Schriften,
Texte, Aufbau und Animationen direkt aus dem Code ablesen und in React umsetzen.

Mitarbeiter:
- Splash.dc.html         Start-Animation mit Logo
- Sprache.dc.html        Sprache wählen (5 Sprachen, Arabisch von rechts nach links)
- Main.dc.html           Start: Bereiche des Tages (alle 5 Sprachen über den Tweak "sprache")
- Scan.dc.html           Kamera mit Erkennung (Geisterbild und Blitz-Knopf noch ergänzen)
- Rueckfrage.dc.html     KI fragt nach (Zahl tippen oder sagen)
- Bestaetigen.dc.html    Ergebnis als Kachel-Raster
- Gespeichert.dc.html    Erfolgsmoment
- Weggeworfen.dc.html    Weggeworfen melden

Chef:
- Assistent.dc.html      Start: Abend-Briefing, Tagesgericht-Idee, Mikrofon
- Antwort.dc.html        So antwortet der Assistent (Satz, Zahlen, Quelle, Aktion)
- Bestand.dc.html        Warenwert, Ampel, läuft bald ab, nach Bereichen
- Einkauf.dc.html        Einkaufsliste für morgen, teilen
- Verlust.dc.html        Weggeworfen im Monat
- Einstellungen.dc.html  Darstellung (Hell/Dunkel/Automatisch, Akzent, Glas)
- *-dunkel.dc.html       Dunkelmodus der Chef-Screens

Noch nicht gezeichnet, laut THECHEF.md aber Pflicht: Einrichtung (Bereiche,
Foto-Positionen, Produktkatalog), Geisterbild im Scan, Offline-Anzeige,
Briefing-Zustand "Heute nicht gescannt".
